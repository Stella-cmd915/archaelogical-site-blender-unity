# Archaeological Site — Blender Model & Unity First-Person Tour

A 3D archaeological sanctuary generated with Blender Python and explored in Unity with a first-person controller and information points.

## Tech stack
- Blender (Python API)
- Unity (C#)

## Features
- Procedural site modelling and renders
- FBX export pipeline
- Unity scene-setup editor window
- First-person controller, info points and tour HUD

## Getting started
1. Run the scripts in `blender/` in order.
2. Open `unity/` in Unity Hub.
3. Use the **Project** menu to set up the scene and build.
